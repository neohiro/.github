# neohiro account defaults

Community health files in this repository act as **account-wide defaults** for every repository under [neohiro](https://github.com/neohiro) that does not ship its own:

- CONTRIBUTING.md
- CODE_OF_CONDUCT.md
- .github/ISSUE_TEMPLATE (bug + feature request forms)
- .github/PULL_REQUEST_TEMPLATE.md

The real profile lives at [neohiro/neohiro](https://github.com/neohiro).
